# Nocturne Lab

Personal portfolio built with TanStack Start, React, TypeScript, and Tailwind CSS.

## Development

```sh
npm install
npm run dev
```

The development server runs at http://localhost:8080.

## Validation and build

```sh
npm run lint
npx tsc --noEmit
npm run build
```

Production builds use Nitro with the Cloudflare module target.
